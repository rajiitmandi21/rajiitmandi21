# SplitKar

**Status:** Private core project with a public UI repository

SplitKar is a full-stack expense splitting application with separate frontend and backend concerns, authentication, authorization, group expenses, settlements, and testing.

## Stack

- Next.js / React / TypeScript
- Node.js / Express
- PostgreSQL
- JWT authentication
- Role-based authorization
- API security and validation

The main implementation is private. A public UI repository is available for selected frontend work.
