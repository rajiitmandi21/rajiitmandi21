# SplitKar

**Status:** Private core project with a public UI repository

SplitKar is a web-based shared-expense management application for groups. Its core scope is expense tracking, flexible splitting, balance/debt visibility, and manual settlement logging rather than payment processing.

## Product scope

- Authentication and onboarding
- Group creation and member management
- Shared expenses with equal, percentage and exact-amount splits
- Per-group and overall balance summaries
- Debt relationships and manual settlement history
- Activity and notification flows
- User profile and account settings

## Technical direction

- React + TypeScript frontend
- Node.js / Express backend
- PostgreSQL
- JWT authentication
- Role/ownership-based authorization
- Validation and API security

The private repository contains the core application and backend. A separate public UI repository exposes selected frontend work.
